# Data Science Professional Program

This repository accompanies Ethnotech Academy's Data Science Professional Program for CSE (AI). The program combines programming, statistical modeling, machine learning, deep learning, big data analytics, data visualization, and cloud platforms through practical work with real-world datasets.

## Program Focus

- **Python for Data Science:** NumPy, Pandas, data import and export, data cleaning, and preprocessing.
- **Statistics and Probability:** Descriptive statistics, probability distributions, hypothesis testing, correlation, and regression.
- **Data Visualization and Analytics:** Visual storytelling, dashboards, relational databases, SQL, and business insights.
- **Machine Learning:** Supervised and unsupervised learning, model evaluation, cross-validation, hyperparameter tuning, clustering, and dimensionality reduction.
- **Applied Data Science:** Building predictive models, applying AI techniques, and communicating insights for decision-making.
