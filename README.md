# Ethnotech Internship Projects

This repository showcases projects I developed during my internship at Ethnotech. The projects apply data analysis and machine learning to practical prediction tasks and present results through interactive applications.

## Projects

### Customer Churn Prediction Dashboard

**Objective:** Identify customers at risk of leaving a service and explore churn patterns to support retention decisions.

**Skills and tools:** Python, Pandas, NumPy, XGBoost, scikit-learn, Streamlit, Plotly, data visualization.

### Car Price Prediction

**Objective:** Estimate a vehicle's market price from its specifications to support car valuation.

**Skills and tools:** Python, Pandas, NumPy, scikit-learn, regression, feature engineering, FastAPI, HTML, CSS, JavaScript.

### Customer Churn Prediction Model

**Objective:** Predict whether a telecom customer is likely to churn based on customer data.

**Skills and tools:** Python, data preprocessing, categorical encoding, feature scaling, model training, scikit-learn.

### Loan Approval Prediction

**Objective:** Estimate a loan application's approval outcome from applicant and financial information.

**Skills and tools:** Python, Pandas, scikit-learn, Logistic Regression, preprocessing pipelines, Streamlit.

## Skills Demonstrated

Python programming, data cleaning and preprocessing, exploratory data analysis, feature engineering, classification and regression, model evaluation, data visualization, and building interactive applications.
